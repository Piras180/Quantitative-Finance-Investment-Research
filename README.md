# Quantitative Finance & Investment Research

This repository contains empirical finance and portfolio management projects developed during my **MSc in Finance at HEC Lausanne**, specializing in **Asset & Risk Management**.

The aim is to apply financial theory and quantitative methods to practical questions in **market forecasting, risk analysis, and portfolio construction**, with an emphasis on transparent methodology and out-of-sample evaluation.

## Repository Structure

| **Project** | **Main Topics & Methods** |
| --- | --- |
| [**Macro Return Forecasting**](./Macro_Return_Forecasting/) | Equity return predictability, oil shocks, Treasury yield curve, OLS, ARX/VAR models, rolling forecasts |
| [**Multivariate GARCH & Volatility**](./Multivariate_GARCH_Volatility/) | Volatility persistence, dynamic stock–bond correlations, GARCH/DCC, regime analysis, risk-based allocation |
| [**Net-Zero Asset Allocation**](./Net_Zero_Asset_Allocation/) | Emerging-market equities, minimum-variance and tracking-error optimization, carbon footprint constraints, net-zero targets |

Each project folder contains a **Python notebook**, a **research report**, and a README describing the research question, methodology, and main findings. These are academic group projects; contributors are acknowledged in the individual project reports.

## Technical Stack

- **Programming:** Python (pandas, NumPy, SciPy, statsmodels, Matplotlib), Jupyter Notebook.
- **Financial Data & Tools:** LSEG Datastream (academic datasets), Excel.
- **Methods:** Financial econometrics, time-series analysis, volatility modelling, constrained portfolio optimization, rolling-window estimation, and out-of-sample backtesting.
